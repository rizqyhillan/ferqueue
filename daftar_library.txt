DAFTAR LIBRARY PROJECT FERQUEUE
================================

1. COMPUTER VISION (apps/computer-vision)
-----------------------------------------
A. Data & Preprocessing (requirements/data.txt)
- Pillow==10.4.0              : Baca/tulis & manipulasi gambar
- numpy==1.26.4               : Komputasi array numerik
- opencv-python==4.10.0.84    : Pengolahan citra (termasuk preprocessing LAB-CLAHE)

B. Inference & Live API (requirements/inference.txt)
- tensorflow==2.15.1          : Menjalankan inferensi model SSD MobileNet V2 FPNLite
- numpy==1.26.4               : Komputasi array numerik
- Pillow==10.4.0              : Manipulasi gambar
- opencv-python==4.10.0.84    : Pengolahan citra

C. Training & Evaluasi (requirements/training.txt & training-cuda.txt)
- tensorflow==2.15.1          : Framework deep learning (atau tensorflow[and-cuda]==2.15.1 untuk GPU)
- keras==2.15.0               : High-level neural network API
- tf-keras==2.15.1            : Kompatibilitas Keras untuk TensorFlow 2.15
- tensorboard==2.15.2         : Visualisasi log & metrik training
- tf-models-official==2.15.0  : TensorFlow Object Detection API
- tf-slim==1.1.0              : Utility layer/decoder untuk Object Detection API
- tensorflow-text==2.15.0     : Dependensi tf-models-official
- tensorflow-io==0.36.0       : I/O tambahan TensorFlow
- tensorflow-datasets==4.9.3  : Utilitas dataset TensorFlow
- tensorflow-metadata==1.14.0 : Metadata dataset TensorFlow
- pycocotools==2.0.7          : Evaluasi metrik COCO (mAP, IoU, dll.)
- lvis==0.5.3                 : Evaluasi deteksi objek (dependensi OD API)
- protobuf==3.20.3            : Serialisasi pipeline config & label map
- lxml==5.3.0                 : Parsing XML
- PyYAML==6.0.2               : Parsing file konfigurasi YAML
- gin-config==0.5.0           : Konfigurasi dependensi tf-models-official
- matplotlib==3.8.4           : Plotting grafik & visualisasi hasil
- pandas==2.1.4               : Olah data tabel & laporan evaluasi
- scipy==1.11.4               : Komputasi ilmiah
- contextlib2==21.6.0         : Utilitas context manager (dependensi OD API)
- pyparsing==2.4.7            : Parser (dependensi matplotlib/OD API)
- six==1.16.0                 : Kompatibilitas Python
- setuptools==80.9.0          : Penyedia pkg_resources untuk TensorBoard 2.15

D. Tambahan di Notebook Eksperimen (apps/computer-vision/notebooks/)
- scikit-image                : Ekstraksi fitur PCV klasik (HOG & GLCM)
- rembg                       : Segmentasi/hapus background (ISNet)
- onnx                        : Format model ONNX
- onnxruntime                 : Runtime inferensi model ONNX/ISNet
- torch & torchvision         : Eksperimen perbandingan arsitektur deteksi objek
