PANDUAN OPERATOR

Alur pemeriksaan

  1. Periksa tampilan kendaraan

    Aktifkan kamera perangkat atau unggah gambar JPG, PNG, atau WebP. Tombol ambil gambar menyimpan foto ke perangkat.

  2. Konfirmasi berat dan golongan

    Kamera mengenali jenis kendaraan. Pilih golongan melalui tombol Ubah. Pengukuran dimensi belum tersedia.

  3. Isi nama pengemudi

    Pastikan nama pengemudi sesuai identitas pengemudi kendaraan sebelum menerbitkan tiket.

  4. Terbitkan dan cetak tiket

    Tiket disimpan di riwayat browser ini. Pilih Cetak tiket untuk mencetak atau menyimpan PDF melalui dialog cetak browser.

Sistem terintegrasi: data berat dan evaluasi anomali dikirimkan secara otomatis melalui Flask Backend.
